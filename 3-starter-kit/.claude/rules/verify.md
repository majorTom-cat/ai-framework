# 검사·조회의 «참값» 규칙 — 초록은 근거가 아니다

> ★**`paths:` 없음(상시 로드)** — 조건부로 두면 셸로 읽을 때 무음이 되는데, 이 규칙은 **어기면 «검증했다»가 거짓이 되는** 층이라 상시여야 한다.
> 뿌리는 하나다: **실패의 «모양»과 성공의 «모양»이 같아지면 사람은 초록만 보고 넘어간다.** 아래 셋은 그 모양이 겹치는 실측 사고들이다.

## 1. 종료 코드 «하나»로 합격을 판정하지 마라 — «몇 건 돌았나»를 같이 봐라
- 2026-09-09 실측(bnsone #240): 돌연변이 5종을 넣고 `npx vitest run … >/tmp/mut.out` 로 돌렸는데 **`/tmp` 쓰기가 막혀 리다이렉트 «설정» 단계에서 실패**했다. 셸이 0 아닌 값을 돌려줬고, 스크립트가 그것을 «테스트 실패 = 돌연변이를 잡았다»로 읽어 **5종 전부 «✅ 잡았다»로 찍혔다. 테스트는 한 번도 안 돌았다.**
- ⇒ 검사 스크립트는 **«못 돌았다»와 «돌았는데 실패»를 갈라야 한다.** 최소 셋을 넣어라: ①**대조군**(아무것도 안 바꾸고 1회 — 여기서 초록이 안 나오면 그 뒤는 전부 무효) ②**「Tests N passed」 같은 «건수» 줄 파싱** ③**준비 실패는 «불합격»이 아니라 «검증 불능»으로 따로 보고.**
- 같은 뿌리: **파이프가 종료 코드를 삼킨다**(`cmd | tail` = `tail` 의 0). 합격/불합격을 내는 검사는 자르지 말고 그대로 돌리고 `echo "EXIT=$?"` 로 눈으로 확인하라(정본 = `CLAUDE.md` '작업 절차').

## 2. `||` 로 감싼 조회는 «실패»와 «빈 결과»를 같은 모양으로 만든다
- 2026-09-08 실측(bnsone #228): `psql -U postgres -d app_dev_jiyeon … || echo "표 없음"` 에서 **role 도 DB 도 없어 명령 자체가 실패**했는데 화면엔 「표 없음」만 남아 «마이그레이션 미적용»이라는 틀린 근거가 됐다(결론은 우연히 같았다).
- ⇒ **「없다」를 단정하기 전에 «조회가 성공했나»부터 봐라.** `||` 로 기본값을 씌우려면 종료 코드를 먼저 잡아라(`out=$(cmd); rc=$?`). 이름·경로·DB명은 **짐작하지 말고 실물에 물어라**(`psql -U {실제계정} -l` 처럼 목록을 내는 명령).
- 같은 뿌리: **잘린 조회(`head`·`per-page`)로 «없다»를 말하지 마라** — 0건은 부재의 근거가 아니다.

## 3. 검사 스크립트의 출력은 «울타리 밖» 경로로 보내지 마라
- `/tmp`·`$TMPDIR` 는 세션에 따라 쓰기가 막힌다. **세션 스크래치패드**(시스템 안내가 알려 주는 경로)로 보내라 — 막힌 리다이렉트는 위 1번의 거짓 초록으로 바로 이어진다.
- ★**통합 테스트가 `Can't reach database server` 나 `Environment variable not found: DATABASE_URL` 로 죽으면 DB 가 아니라 «울타리»를 의심하라.** 2026-09-08 실측(bnsone #228): 30분 전까지 멀쩡히 돌던 테스트가 죽었는데 **DB 는 정상**이었다(`docker compose exec db psql` 로 행이 보인다). 안내가 전부 «DB 가 떠 있나»만 가리켜 원인에 못 닿았다. 확인법: `nc -z localhost {포트}` 와 `.env` 읽기를 **울타리 안에서** 각각 재라.
- 킷 자기시험(`scripts/test-*.sh`)은 **스크래치패드로 옮긴 뒤 절대경로로** 돌려라 — 저장소 루트에서 돌리면 픽스처·`git init` 이 저장소에 떨어진다(2026-09-09 실사고).

## 4. 새 검사를 만들었으면 «그 검사가 산다»를 증명하라
- 초록도 건수도 근거가 아니다. **기대를 일부러 뒤집어 FAIL 이 나는지**를 한 번 돌려 봐라.
- 2026-09-10 실측: `test-check-push.sh` 가 사유 문구만 grep 해서 **확인 창을 알림으로 바꿔도 56/56 초록**이었다 — 창을 없앤 것도, 실수로 없어진 것도 시험이 증명하지 못했다. 판정 «종류»를 검사에 넣고 기대를 뒤집으니 3건이 FAIL 했다.
- **«세는 잣대»가 대상의 실제 모양과 다르면 0이 나온다** — 세기 전에 그 파일의 첫 줄을 눈으로 봐라.
