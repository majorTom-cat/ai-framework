# 공통 영역(shared) 규칙 — 이 파일들은 전원에게 영향을 준다

> 상시 로드(`paths:` 없음) — 공용 코드는 어기면 **전원이 깨지는** 층이라 조건부에 둘 수 없다(조건부 규칙은 셸로 읽으면 무음 — `_reference/rules-loading.md`).

- **추가는 자유, 삭제·변경은 신중**: 기존 export 를 없애면 공개 API 스냅샷 테스트가 실패한다. 스냅샷이 이름만 기록하면 시그니처 변경(인자 순서·의미)은 못 잡는다 — 최종 방어선은 전 모듈 테스트다(스냅샷에 시그니처 해시를 포함하면 더 좋음 — 공통 개발자 가이드 Day 4).
  - 의도적 변경이면 스냅샷 갱신 커밋 + 전 모듈 테스트 통과 + 채팅 공지가 조건.
- 기존 동작을 바꿔야 하면: ①새 버전을 옆에 추가 → 호출부 이전 → 구버전 제거(확장→이전→축소), 또는 ②같은 MR 에서 전 모듈 호출부를 함께 수정("깨뜨린 사람이 고친다") + 해당 소유자 @멘션.
- **새 컴포넌트를 여기 추가하기 전에**: 2개 이상 모듈이 실제로 쓰거나 둘째 사용처 카드가 확정됐는가(정본 = 루트 `CLAUDE.md` '소유 경계')? 아니면 자기 모듈에 둔다.
- 공지·push 확인 규칙 정본 = 루트 `CLAUDE.md` '소유 경계'.
