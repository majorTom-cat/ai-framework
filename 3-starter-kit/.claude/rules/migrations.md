# 마이그레이션 규칙

- 파일명 = `YYYYMMDD_HHMMSS_설명.<확장자>` (확장자는 프로젝트 마이그레이션 도구 표준 — 킷 도입 시 치환). **초 단위 필수** — 분 단위는 병렬 작업 시 같은 분 충돌이 실제로 난다. 같은 초라면 파일명 사전순이 적용 순서다
- **main에 머지된 마이그레이션 파일은 수정·삭제 금지(불변).** 고칠 것도 새 파일로.
- 되돌리기는 down이 아니라 "되돌리는 내용의 새 마이그레이션" 추가 (forward-only).
- 자기 모듈 테이블은 자유(추가 위주). **공용 테이블(users 등)의 이름변경·삭제는 확장→이전→축소 3단계 + 채팅 공지.**
- 스키마 변경 MR에는 해당 모듈 시드(멱등: 있으면 갱신·없으면 생성) 갱신을 같이 포함한다.
