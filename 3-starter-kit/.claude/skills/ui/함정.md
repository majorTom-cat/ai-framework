# /ui 함정 목록 — 실측 예외 모음 (본문이 가리킬 때 읽는다)

> 여기 있는 것은 전부 **실제로 겪은 실패와 그 우회**다. 본문이 "함정.md §N"을 가리키면 해당 절만 읽어라.

## §1 glab 카드·MR 생성의 무음 실패 (본문 깨짐·무기한 행)

- 여러 줄 본문을 `-d`에 직접 넘기지 마라 — **파일로 쓴 뒤 `-d "$(cat 파일)"` + `</dev/null`**(안 그러면 인자가 쪼개지거나 Windows에서 무기한 행 — 정본은 `rules/gitlab-cli.md`).
- **생성 직후 재조회로 확인한다**(`glab issue view <번호>` / `glab mr list`) — 무음 실패·본문 깨짐은 조회로만 잡힌다. 루프·연속 생성에서 `</dev/null` 누락 시 **출력 한 줄 없이 무음 실패**한다(브랜치만 올라가고 MR 없음 — 파일럿 2026-08-04 실측 2건).
- 시안 선택 카드는 재조회에서 **체크박스 줄(`- [ ]`)이 살아 있는지 · 허브 링크가 안 깨졌는지 · 담당이 결정권자인지**까지 본다 — 체크박스가 뭉개지면 결정권자가 고를 수단 자체가 없어진다. 그 자리에서 `glab issue update`로 고친 뒤 카드번호를 사용자에게 알린다.

## §2 `Closes #N` 자동 닫힘 — 시안 카드에는 특히 치명

- MR 본문·커밋에 `Closes`(`Fixes`·`Resolves` 포함)를 쓰면 **머지 순간 GitLab이 그 카드를 자동으로 닫는다** — 수용 기준이 남은 카드가 머지와 동시에 닫혀 되돌린 실사고(bnsone 2026-08-05). 본문엔 `관련: #N`으로 링크만 건다.
- 갈래 1(후보 발행)에서 닫히면: 시안 선택 카드는 **아직 아무도 고르지 않은 카드**다 — 선택 게이트가 통째로 증발한다.
- 갈래 2(채택)에서 닫히면: 결정 기록(증거 댓글) 없이 닫히고 다른 카드까지 딸려 닫힐 수 있다 — 카드는 **댓글·증거를 남긴 뒤 `glab issue close`로 명시적으로** 닫고, 재조회로 닫힘·댓글을 확인한다(§1).

## §3 시안 열람 방식 — 기각된 경로 (다시 검토하지 마라)

- **기각**: GitLab 파일뷰(코드로만 보임) · 채팅 HTML 전송(다음 세션의 AI도 못 읽음) · 스크린샷 이미지(잘림·인터랙션 불가) · 화면공유(비동기 불가). GitLab Design Management는 18.6에서 deprecated.
- 정답은 시안 허브뿐 — 링크 클릭 시 브라우저에서 실물 HTML(스크롤·버튼 동작), 이미지가 아니다. 앱 검수 서버와는 별개 인스턴스.
- **GitLab CE 체크박스는 상호배타가 안 된다**(라디오 아님 · 스코프 라벨은 유료) — 카드에 "하나만 체크"를 명시하고, 여러 개 체크는 갈래 2의 미결정 정지가 막는다.

## §4 시안 허브가 미설정일 때 (HTML부터 만들지 마라)

- `CLAUDE.md` ★실행 절의 시안 허브 URL이 리터럴 `<시안허브URL>`로 남아 있으면 미설정 — 만들어도 **아무도 볼 수 없다.**
- 안내문: "공통 개발자가 시안 허브 세팅 먼저(→ `docs/00_Guide/sian-hub-setup.md`) — 또는 인스턴스에 GitLab Pages가 정상이면 각 프로젝트 CI `pages` 잡."
