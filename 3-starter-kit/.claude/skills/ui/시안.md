# /ui 시안 모드 — 후보 생성·채택 확정 (본문 '시안 모드'가 가리킬 때 읽는다)

> 인자가 `시안 …`이면 **이 파일이 절차 정본**이다. 본문(SKILL.md)의 모드 분기·진입 판정을 통과한 뒤 여기로 온다.
> 함정(무음 실패·자동 닫힘·기각된 열람 경로·허브 미설정)은 같은 폴더 `함정.md`.

### 갈래 1) 후보 생성 — `시안 {화면이름}` (구현 전, 화면당 1회)

1. `git pull` 후 **그 화면과 관련된 요구만** 읽는다 — `_digest.md` + 근거 절(통독 금지).
   - **요구 문서가 아직 없는 화면이면**(digest에 그 영역이 없음): 감으로 지어내지 마라 — 기획자에게 요구를 요청(`/card {화면} 요구 문서 요청`)하거나,
     있는 **백엔드 계약**(그 모듈 `index`의 공개 함수)·유사 화면을 데이터 앵커로 삼고 **미정 항목(카테고리·핀·페이지네이션 등)을 `notes.md`에 "미해결"로 명시**한다.
   - 디자인 시스템(`docs/05_UIUX/design-tokens.md`·`src/shared/ui`)이 있으면 그 안에서, 없으면 이 시안이 씨앗이 됨을 인지(씨앗은 채택/구현 때 심는다 — 시안은 `docs`만).
2. **구조가 다른 2~3안** — 장식이 아니라 **레이아웃·동선이 다른 안**(예: A=큰 버튼 · B=대시보드 · C=단계형). 각 안 컨셉 한 줄. 안들이 **AI 상투 3종**(목록 정본 = SKILL.md 구현 §1)으로 수렴하면 고를 의미가 없다 — 적어도 한 안은 상투 밖에서.
   - **색·타이포·톤은 `docs/05_UIUX/design-tokens.md`(디자인 아이덴티티 정본)가 있으면 그걸 따르고, 없으면 기존 채택 시안의 토큰 계열을 유지**한다 — 안마다 다른 건 구조지 정체성이 아니다.
   - (정본이 아직 없고 채택 시안이 2개+ 쌓였으면 "토큰을 추출해 정본을 만들자"고 공통 개발자에게 제안)
3. **시안 선택 카드부터 만든다**(번호가 있어야 커밋·채택 명령이 가리킨다) — **`/ui`가 glab로 직접 생성**(`/card`엔 체크박스 양식이 없다). **결정권자(assignee)** = 차터의 기획/결정권자 또는 소유표의 그 모듈 소유자 — **불명확하면 사용자에게 물어라**(초기엔 보통 공통 개발자):
   ```
   glab issue create --title "{화면} — 시안 선택" --assignee <결정권자아이디> -d "$(cat {본문파일})" </dev/null
   ```
   본문 = **GitLab task list 체크박스**(허브 링크 = `<시안허브URL>/<프로젝트>/screens/{화면}/시안X.html`):
   ```
   ## {화면} 시안 — 하나만 체크하세요 ✅ (댓글 아님)
   - [ ] **A안** · {A 컨셉} — [열기](<시안허브URL>/<프로젝트>/screens/{화면}/시안A.html)
   - [ ] **B안** · {B 컨셉} — [열기](…/시안B.html)
   체크하면 개발자가 `/ui 시안 채택 {화면} <안> #<이 카드번호>` 로 확정 → 갤러리·notes에 자동 기록.
   ```
   ★**카드를 만들기 전에 `함정.md` §1을 읽어라**(본문 파일·`</dev/null`·생성 직후 재조회 — 체크박스 생존 확인까지) — 무음 실패·본문 깨짐은 조회로만 잡힌다. 확인 후 카드번호를 사용자에게 알린다.
4. **파일 생성**:
   - `docs/05_UIUX/screens/{화면이름}/시안A.html`·`시안B.html`(·`C`) — 각각 **자기완결 단일 HTML**(인라인 CSS, 더미 데이터로 실감), **375px 모바일 우선**+데스크톱, 핵심 상태(빈·에러) 표현.
     - **외부 요청 0**(CDN 폰트·스크립트 금지 — 시스템 폰트 스택·인라인만. 사내망에서 CDN이 막히면 검수자마다 다른 화면을 본다).
     - **`<body>` 직후에 갤러리 복귀 링크 고정 배지**(`<a id="back-badge" href="../../index.html">← 시안 갤러리</a>`, 화면 좌상단 고정·작게) — 없으면 열람자가 뒤로 갈 길이 없어 URL을 지워야 한다.
       **+배지 뒤 스크립트에 두 줄**: ①`if(self!==top)document.getElementById('back-badge').style.display='none'` — 갤러리 비교 보기가 시안을 iframe으로 띄우는데, 이게 없으면 두 패널 안에 배지가 또 떠서 겹친다(bnsone 실측).
       ②**더미 링크 이력 차단**: `document.addEventListener('click',function(e){var a=e.target.closest&&e.target.closest('a[href="#"]');if(a)e.preventDefault();})` — 시안 속 GNB·로고 등 `href="#"` 링크를 눌러보는 순간 iframe 이력이 쌓여 **갤러리 뒤로가기를 삼킨다**(bnsone !165 실측 — 시안 7종 소급 패치).
     - **동선 표기**: 화면 이동이 일어나는 주요 버튼·링크에 **작은 `→ {목적지 화면}` 배지**를 단다(목적지 미정이면 `→ (미정)`). 시안 속 링크는 더미라 눌러도 안 간다 — **"어디로 가는 설계인가"를 보는 사람이 알게 하는 게 목적**이다. 배지는 시안의 인상을 해치지 않게 작게(각주풍 — 스타일 자유).
   - `notes.md` — 안별 컨셉·차이 표 + **동선 표**(주요 요소 → 목적지 화면 — 안끼리 동선이 다르면 그 차이가 곧 비교 포인트) + 맨 끝에 `## 선택` **미결정 블록**(`> ⏸ 미결정 — 선택: __안 · 이유: __ · 결정일: __ · 결정자: __`).
   - **갤러리 `docs/05_UIUX/index.html`** — 없으면 **`.claude/skills/ui/gallery-template.html`을 그 자리로 복사**하고 `<프로젝트>`를 채운다. 예시 `<section>`과 **똑같은 구조**로 이 화면 섹션을 마커 주석(`▲ 새 화면 …`) 위에 추가한다 → 허브가 이 index.html을 그대로 보여준다(화면 여럿이면 섹션이 쌓임).
     섹션 규칙: `picked-tag`는 `hidden`인 채, **안 링크에 `data-label` + `onclick="return cmpNav(this, event)"` 유지** — **안 클릭 = PC+모바일(오른쪽 375px) 병렬**이 기본 동작이다(별도 버튼 아님 — 결정권자는 안 이름을 누르지 버튼을 찾지 않는다. 원본 단독은 수식키 클릭·오버레이 "원본 새 탭 ↗", 폰(<820px)은 그냥 이동).
     ※기존 갤러리가 **구판**(템플릿의 스타일·스크립트 블록과 다르면 전부 — 비교 오버레이 `#cmpov` 없음·별도 📱🖥 버튼·모바일 왼쪽·**접기(.folded) 없음** 등)이면 이번 섹션 추가·채택 때 템플릿의 스타일·오버레이·스크립트 블록으로 갈아 끼운다(기존 섹션 내용은 손대지 않되 안 링크에 `onclick`·`data-label`은 붙인다).
     ★**섹션 notes 줄에 선택 카드 링크 필수** — `고르러 가기 → 카드 #<선택카드번호>`(3단계에서 만든 카드의 web_url). 허브만 보는 결정권자가 그 카드를 찾아갈 유일한 길이다.
5. **발행**: `#<카드번호> 시안: {화면} 후보` 로 커밋 → **브랜치→MR→main 머지**(팀 규칙: main 직접 push 금지). 머지되면 git-sync가 ≈30초 뒤 허브에 올려 카드의 링크가 살아난다.
   — ★**MR 본문에 `Closes #N` 금지 — `관련: #N` 링크만**(이유는 **함정.md §2**). MR을 만들기 전에 **`함정.md` §1을 읽어라**(본문 파일·`</dev/null`·생성 재조회).
   - **시안 요청 카드에서 출발했으면**(기획자 발주 — `/card` 유형) 그 요청 카드에 "후보 발행 — 선택은 #<선택카드번호>" 댓글(증거 = 선택 카드·허브 링크) + **`셀프완료` 라벨 전환** 후 닫는다(화면 없는 발주 카드 = 셀프완료 예외 — 라벨이 기록 정본, 절차는 /done 8단계).
6. **⏸ 선택 게이트 — 여기서 멈춘다. AI는 고르지 않는다.**
   - 열람 = **시안 허브** `<시안허브URL>/<프로젝트>/` 뿐이다 — 다른 열람 방식은 전부 기각됐다(목록·이유 = **함정.md §3**. 다시 검토하지 마라).
   - **⚖️ 역할 경계**: 시안 선택 = 구조·배치·정보 우선순위. 세부 인터랙션은 구현 단계(`?preview=`)의 몫.
   - ▶ 다음: 결정권자가 허브에서 보고 카드 체크 → `/ui 시안 채택 {화면} {안} #<카드번호>`.

### 갈래 2) 채택 확정 — `시안 채택 {화면} {안} [#카드번호]` (체크됐거나 결정권자 지시가 있을 때만)

결정을 **댓글 한 줄이 아니라 3곳에 기록으로** 남긴다(나중에 STEP6 설계·STEP7 개발 입력):
0. **카드 찾기 + 체크 상태 확인**: 인자의 카드번호(없으면 `glab issue list --search "{화면} 시안 선택"`) → `glab issue view`로 체크 상태(`- [x]`)를 읽는다.
   - **2개 이상 체크 = 아직 미결정 — 멈춰라**("하나만 남겨 주세요" 요청. **AI가 임의로 고르지 마라**) / **인자 `{안}` ≠ 체크된 안** → 어느 게 맞는지 확인 후 진행 / **0개 체크(구두 지시만)** → 지시받은 안으로 진행하되 그 줄을 `- [x]`로 바꿔 기록을 일치시킨다.
   - **체크·구두 지시 둘 다 없음** → 채택하지 말고 멈춰라 — "아직 선택 전"으로 보고 허브 링크와 함께 카드 체크를 재안내.
   - **댓글에 혼합·수정 요청("A 레이아웃 + B 색")이 있으면** 그대로 채택하지 말고 멈춰라 — **혼합안을 새 후보로 추가**(갈래 1 보강 재실행 — 기존 안 유지)한 뒤 다시 고르게 안내(GitLab 가이드 §5-1이 사용자를 이 경로로 보낸다).
   - ★**후보를 추가·수정해 재발행했으면 선택 카드에 "요청하신 {안} 올렸습니다 — 허브에서 확인" 댓글을 남긴다** — 본문 목록만 갱신하면 결정권자가 새 안의 존재를 모른 채 대기한다(bnsone #77 실측 2026-08-19). 단 **같은 취지 재촉 댓글 반복은 금지**(새 산출물 알림 ≠ 재촉 — 오너 지적 08-18).
1. **갤러리** `index.html` 그 화면 섹션(gallery-template 클래스 그대로): `picked-tag`의 `hidden` 제거 + 텍스트 `· 선택: {안}` / **`<section class="screen">`에 `folded` 클래스 추가**(결정된 화면은 접힌 채 시작 — "화면 · 선택: {안}"만 보임. 모든 화면이 제목 클릭으로 접힘/펼침이라 열람자가 수동으로도 접는다).
   이어서: 채택안 링크에 `class="picked"` / 나머지 안 링크에 `class="dropped"` + `href`를 `_drafts/{화면}/시안X.html`로(비교 보기는 `href`를 따라가므로 그걸로 끝) / notes 줄을 "채택: {안}"으로 + **카드 링크 텍스트를 `고르러 가기 →`에서 `결정 기록 →`으로**(링크는 유지 — 닫힌 카드가 곧 결정 이력).
2. **notes.md** `## 선택` 블록을 **안·이유·결정일·결정자**로 채움 + **탈락안 파일은 `docs/05_UIUX/_drafts/{화면}/`로 이동**(삭제 ❌ — 이력). **이미 채택 이력이 있으면(번복)** 옛 줄을 지우지 말고 "변경: {옛안}→{새안}(날짜·사유)"로 **병기**.
   — **채택을 무르는 경우**(어느 안도 아님 — 미결정 복귀): 갤러리 섹션의 `folded` 제거(다시 펼쳐진 채 시작)·`picked-tag`에 `hidden` 복원·notes에 "변경: 채택 철회(날짜·사유)" 병기 + **선택 카드를 다시 연다**(또는 새 선택 카드 — 닫힌 카드가 결정 이력이므로 재오픈 사유 댓글 필수). `_drafts/`로 옮겼던 탈락안은 `screens/`로 복귀.
3. **카드**: 결정 요약 댓글(증거 = 갤러리·notes 링크) + **`셀프완료` 라벨 전환**(라벨이 기록 정본 — 절차는 /done 8단계) + **닫는다**(시안 선택 카드는 화면 없는 **docs·결정 카드** → 셀프완료 예외. 검수 카드가 아니다).
   `docs/_STEP_INDEX.md` STEP 5 행을 **🔄 진행**+링크로 갱신(화면 하나 채택 ≠ STEP5 완료 — 전 화면 채택·구현돼야 ✅). `#<카드> 시안: {화면} {안} 채택`으로 커밋 → MR → 머지.
   — ★**카드는 댓글·증거를 남긴 뒤 `glab issue close`로 명시적으로 닫고 재조회로 확인한다. `Closes #N` 금지** — **닫기 전에 `함정.md` §2를 읽어라**(재조회는 §1).
→ 머지 후 git-sync가 허브 갤러리를 "채택됨"으로 갱신. 채택안이 이 화면의 **정본 시안**(/dev·구현 /ui가 참조).
▶ 다음: 화면 카드 없으면 `/card {화면} 구현`, 있으면 `/dev {번호}`.

⛔ 시안 모드 금지: 앱 코드(`src/`) 수정(시안은 docs만) · AI가 임의로 안을 선택·폐기 · 안끼리 장식만 다르게(구조가 달라야 고를 의미가 있다).
