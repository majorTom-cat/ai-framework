# /module — 모듈 "$0" 신설

> **계약** · 입력: 모듈명 · 산출물: 본보기 구조 빈 모듈 + rules/module-*.md (커밋은 다음 /dev) · 검증: src/modules/모듈 생성 → /dev

> **예시**: `/module board` (모듈 이름은 한 단어)

> **★모듈 이름이 안 왔으면 여기서 멈춘다** — 제목의 `"$0"`이 치환 안 됐거나 `/bin/zsh`·`bash` 같은 **셸 이름이면 아래 단계를 하나도 실행하지 마라**(셸이 `$0`을 펼쳐 **`src/modules//bin/zsh` 폴더가 실제로 생긴다** — 쓰기 부작용).
> 이름을 문맥으로 추측하지 말고 `/module {모듈이름}` 으로 다시 부르라고 안내하고 종료한다 — 명령을 고쳐 우회하라는 뜻이 아니라 **실행 자체를 멈추고 되묻는다**는 뜻이다.

0. `git pull origin main` — 뒤처진 main 위에서 생성기를 돌리지 않는다. **`src/modules/$0`가 이미 있으면 중단·보고**(이름 충돌 — 재생성은 소유자 확인 후에만; 덮어쓰면 남의 모듈이 날아간다). **이 모듈의 첫 카드가 없으면 `/card` 로 먼저 만들어 번호를 확보**한다 — 4·5단계의 `#첫카드번호`·`/dev {첫 카드번호}`가 이 번호를 쓴다
1. **정확히 이 명령만 실행하라 (수정 금지):** `npm run gen:module $0` — **단 위 ★정지 조건(이름 미치환·셸 이름)에 걸리면 실행하지 않는다.**
   — **`gen:module` 스크립트 자체가 없으면**: 손으로 만들지 말고 멈추되, **원인을 먼저 가려라**(오진 주의 — 생성기는 `/scaffold` 산출물이 **아니라 Day 6 산출물**이다: 공통 개발자 가이드 "Day 6 — 본보기 모듈 + 생성기").
     ①`src/`·앱 골격 자체가 없으면 → "▶ 다음: 공통 개발자가 `/scaffold` 먼저 (스택 미확정이면 `/design`부터)"
     ②골격은 있는데 생성기만 없으면 → **`/scaffold`를 다시 돌리라고 하지 마라**(2026-07-28 실측: bnsone은 scaffold 완료 상태인데 생성기가 없어 옛 문구가 재실행을 가리켰다). "▶ 다음: 공통 개발자가 **Day 6(본보기 모듈 + 생성기)** 먼저" 라고 안내하라
   — 본보기와 같은 구조가 이름 치환되어 생성된다 (**파일 구성은 생성기 실물이 정본** — 이 문서의 예시와 다르면 생성기가 맞다). 예약 폴더에 있던 "아직 생성 전" README 류는 생성기가 지웠는지 확인
2. 생성된 파일들의 상단 [팀 규칙] 주석을 읽고 요약해서 보여줘라
3. `.claude/rules/_module-template.md` 를 복사해 `.claude/rules/module-$0.md` 생성 — 소유자는 **CLAUDE.md 모듈 소유 표를 먼저 확인**: 내 행이 이미 있으면 그 값을 그대로 쓴다(질문 생략), 없으면 **공통 개발자에게 기입 요청**(표 기입·갱신은 공통 개발자 몫 — 임의 기입 금지)
4. **생성물은 여기서 커밋하지 않는다** — 곧바로 이어가는 `/dev`가 **첫 카드 브랜치의 첫 커밋에 이 스캐폴드를 함께 담는다**(`#첫카드번호` 규칙). /dev는 이 미커밋 스캐폴드를 "더러운 트리 금지"의 예외로 처리하도록 돼 있다
5. **곧바로 `/dev {첫 카드번호}` 로 이어가라** — 게이트(계획 go)에서 no가 나면 생성물을 폐기(`git clean`)해 트리를 깨끗이 되돌린다 (언커밋 스캐폴드를 main 작업트리에 표류시키지 마라)
6. 사용자에게 안내: "본보기 모듈(src/modules/<본보기모듈>)과 나란히 놓고 보면서 개발하세요." + **모듈 지도 갱신**: `npm run boundaries -- --map`(새 모듈이 지도에 실리게).

## ❌ 금지 — 그 순간 드는 핑계와 반박까지

- 생성기 없이 손으로 폴더 만들기 · 본보기 폴더를 복사해 이름만 바꾸기

| 하고 싶어지는 말 (핑계) | 반박 |
| --- | --- |
| "생성기가 에러 나니 이번만 손으로 만들자" | 손 생성 모듈 하나가 구조 변형의 시작점이다 — 생성기 문제를 사용자에게 보고하고 멈춰라 |
| "본보기 폴더를 복사해 개명하면 같잖아" | 복사는 본보기의 데이터·주석·우연한 상태까지 딸려온다 — 이름 치환·초기화는 생성기가 정본이다 |
