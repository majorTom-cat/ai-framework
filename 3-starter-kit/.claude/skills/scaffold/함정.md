## §1 Next 스택 프리뷰 미들웨어 — 이름·위치

- 파일명은 **`proxy.ts`**(16에서 `middleware` 개명·폐기예고, 함수명도 `proxy`) · **`src/` 구조면 반드시 src/ 안**(=app과 같은 층 — 공식 규약 "project root, or inside src if applicable").
- 루트에 두면 **prod는 돌고 dev만 무음으로 안 도는** 비대칭이 난다(bnsone #54 실측 — 전 라우트 Set-Cookie 0건인데 빌드는 정상).

## §2 프리뷰 판정 — 페이지마다 복사 금지

- 프리뷰 판정(쿼리+쿠키 폴백)은 **페이지마다 복사 금지** — shared 헬퍼 1개(`isPreviewEnabled` 류)로 내려 페이지는 한 줄만 부르게 하라(bnsone #51 리뷰 실측 — 4줄이 플래그 페이지마다 복제될 뻔).

## §3 lock 자동 머지 드라이버가 낸 사고 — merge=binary만 쓰는 이유

- ⚠️**자동 머지 드라이버를 두지 마라** — `npm-merge-driver`(6년 미유지)든 자체 스크립트든, git merge 도중 package.json 해결 *전에* lock을 재생성해 **한쪽 의존성이 조용히 누락된 valid-but-wrong lock**을 만든다〔2026-07-27 파일럿 실측〕.
- `merge=binary`는 자동머지 대신 **시끄러운 충돌로 강제**해 수동 해결로 유도한다 — 해결은 CLAUDE.md '금지' 절 규칙: package.json만 통합 → `npm install --package-lock-only`

## §4 시드 무검증 — 검사 넷이 초록인데 CrashLoop 난 경위

- 가장 치명적인데 검증이 없다: bnsone 실측 — 시드의 `$queryRawUnsafe`가 P2010으로 죽어 검수 서버 첫 기동 CrashLoopBackOff인데 `npm test`·typecheck·`ci lint`·CI 잡 넷 다 초록이었다. 넷 중 시드를 돌리는 게 하나도 없다.
- `$queryRaw`↔`$executeRaw` 같은 함정은 스택별이라 규칙으론 못 막고 테스트만 잡는다.

## §5 tamper-check·high-risk-gate의 스택 가정 — 실측 2건과 고치는 패턴

- **라우팅이 `src/app/**`인 스택**(Next.js)이면 `src/app/**/page.*`·`route.*`·`layout.*`·`proxy.*`(구 `middleware.*`)를 `changes:`에 추가.
- **라우팅이 루트 파일인 스택**(단일 `server.js`)이면 그 루트 파일 자체를 추가하고 tamper의 `^src/`도 `^src/|^server\.` 처럼 넓힌다(bnsone은 라우팅 경로 누락·파일럿은 루트 파일 누락으로 고위험 3카드가 게이트 없이 수동 우회 — 2026-07-29 실측).

## §6 모듈 규칙 파일은 골격에서만 찍을 수 있다 (3단계)

- 골격이 `src/modules/{이름}/` 폴더를 **선생성하면 `/module`은 그 모듈에서 영원히 실행되지 않는다** — `/module` 0단계가 "폴더 있으면 중단"이라, 규칙 파일(`.claude/rules/module-*.md`)을 만들 경로 자체가 사라진다.
- 2026-08-25 실측: **bnsone 6모듈 전부 부재**, 파일럿도 골격이 만든 2모듈만 부재(`/module`로 만든 3개는 정상). 사후 보충은 사람이 손으로 해야 했다.
- 그래서 폴더를 찍는 그 자리에서 규칙 파일도 함께 찍는다 — 나중에 하기가 아니다.

## §7 경계검사 경로는 package.json 한 줄로 묶어라 (4단계)

- 스택 변형(`check-boundaries-next.cjs` 등)을 고른 뒤 **스킬 본문의 원경로를 일일이 고치는 방식은 반드시 한 곳을 남긴다.**
- 2026-08-26 bnsone 실측: 스킬 **3곳**이 여전히 기본형 경로(`check-boundaries.cjs`)를 가리키고 있었다 — 검사는 도는데 아무도 안 부르는 상태.
- `npm run boundaries`로 감싸면 변형 선택이 package.json 한 줄에서 끝나고, CI·스킬은 그 이름만 부른다.
