# /assign-module — 모듈 "$0" 소유자 = "$1"

> **계약** · 입력: 모듈 + 소유자 · 산출물: 소유 3곳 동기화(CLAUDE.md 표·rules·GitLab 라벨) **+ docs 파생 표기 정리** 커밋 · 검증: 세 곳 값 일치 (⏸ 승인)

> **공통 개발자 스킬.** 소유는 세 곳(CLAUDE.md 표·`rules/module-*.md`·GitLab 라벨)에 흩어져 있어 **하나만 고치면 어긋난다** — 이 스킬이 한 번에 맞춘다. `/card` 배정·`/start` 진단·`/dev` 소유 확인이 전부 이걸 정본으로 읽는다.

> **예시**: `/assign-module board 홍길동` · `/assign-module 게시판 김하늘` (이름/핸들은 GitLab 계정, 공백 있으면 따옴표)

> **★인자가 안 왔으면 여기서 멈춘다** — 위 제목의 `"$0"`·`"$1"`이 그대로 보이거나 `/bin/zsh`·`bash` 같은 **셸 이름으로 보이면**(인자 없이 부르면 셸이 `$0`을 셸 이름으로 펼친다) 아래 단계를 **하나도 실행하지 마라**: 소유표에 셸 이름 행이 박히고 `모듈:/bin/zsh` 라벨이 실제로 만들어진다. 문맥으로 추측하지 말고 `/assign-module {모듈} {소유자}` 로 다시 부르라고 안내하고 종료.

1. **확인**: `$0`(모듈)·`$1`(소유자)가 다 있나. 소유자를 비웠으면 누구로 할지 묻는다 — **지어내지 마라**(누가 만들었는지·편해서 등으로 추정 금지, 공통 개발자 결정). 소유자가 GitLab 멤버인지 확인 권장(`glab api projects/:id/members`).
2. **① CLAUDE.md 소유표** — `## 소유 경계` 표에서 `$0` 행의 소유자 칸을 `$1`로 (Edit). **행이 없으면 새 행 추가**(플레이스홀더 `<모듈b>` 등 빈 자리면 그걸 `$0`로 교체). 이관이면 옛 소유자를 지우고 `$1`로.
3. **② `.claude/rules/module-$0.md`** — 머리의 `소유자: {이름}`을 `$1`로. **파일이 없으면 이 스킬이 그 자리에서 만든다**: `_module-template.md` 복사 → `paths:`·제목의 `{모듈이름}`을 `$0`로, 소유자를 `$1`로(본문 `<…>`는 소유자가 채운다).
   ★폴더가 이미 있으면 `/module` 은 **3단계(규칙 파일 만들기)만** 수행하는 보충 경로로 돌 수 있다(2026-08-25 `1ea0a00`). 다만 이 스킬은 **소유 표까지 한 번에** 채우므로 배정에는 이쪽이 정본이다(옛 안내 «/module 은 0단계에서 멈춘다» 는 그 커밋 이후 틀렸다(2026-08-25 bnsone #145 오안내 실측).
4. **③ GitLab 라벨** — `모듈:$0` 라벨이 있나 확인, 없으면 `glab label create`. (카드 담당은 `/card`가 이 표에서 읽어 자동 배정 — 여기선 표가 정본.)
   ★**이관이면 여기서 파생 표기까지 훑는다** — `grep -rn "{옛소유자}" --include="*.md" docs/`. 「현재 상태」 문서(digest·기술설계·`_STEP_INDEX`)는 **값을 고치고**, **ADR 은 원문을 지우지 말고 정정 표기를 덧붙인다**(docs 규칙의 대체됨 표지판). 소유 3곳만 맞추면 문서는 그대로 남아 **다음 사람과 AI 가 옛 이름을 읽는다** — 2026-09-07 bnsone calendar 이관 직후 실측 **11곳**이었고, 그중 `adr/0041` 은 「연동이 생기면 **옛담당 앞** 인터페이스 카드」라 그대로 두면 **엉뚱한 사람에게 카드가 간다.** ⚠️**사건 서술·기획자 원문은 소유 표기가 아니다 — 건드리지 마라.**
5. **⏸ 요약 보여주고 승인 후 실행** → 커밋(첫 줄 `#<카드> chore: $0 소유자 $1` — **카드가 없으면 `/card`로 먼저 만든다**). CLAUDE.md·`.claude/**` 수정은 공통 영역이다 — push 전 공지·고위험 게이트 규칙(CLAUDE.md '소유 경계') 적용.
6. 보고 + **"▶ 다음: 소유자에게 `/todo`로 첫 카드 안내 (비었으면 기획자와 `/card`로 비축)"**.

## ❌ 금지
- 소유자를 **지어내기**(공통 개발자 결정 사항).
- 세 곳 중 **하나만 고치기** — 표·rules·라벨이 어긋나면 `/card`·`/dev`가 틀리게 돈다.
- **이관인데 docs 파생 표기를 안 훑기** — 기능은 안 깨지지만 사람과 AI 가 옛 담당자를 읽는다(4단계 ★).
