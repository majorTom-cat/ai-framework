## ❌ 금지 — 그 순간 드는 핑계와 반박까지

| 하고 싶어지는 말 (핑계) | 반박 |
| --- | --- |
| "사소한 수정이니 카드 없이 바로 고치자" | 카드 없는 변경은 이력·검수·이유가 전부 증발한다 — 등록이 1분, 추적 복원은 불가능. **면제는 CLAUDE.md의 예외 2건뿐**(킷동기·검수용 시드 표본 — 커밋 접두어로 이력 유지) |
| "수용 기준은 개발하면서 정하자" | /dev 의 게이트 단축과 검수가 이 필드에 의존한다 — 기준 없는 카드는 검수 불가 카드다 |
| "채팅으로 합의했으니 그걸로 충분" | 합의는 빨리, 기록(카드)은 반드시 — 채팅은 다음 세션의 AI도, 다음 주의 팀원도 못 읽는다 |

## 「다른 모듈 기능을 `index.ts` 로 노출」을 수용 기준에 쓸 때 — 부르는 쪽이 브라우저 부품이면 못 쓴다 (배포처 bnsone #812)
- 브라우저 부품(`"use client"`)은 서버 전용 의존이 든 모듈의 `index.ts` 를 import 할 수 없다. 카드가 «`index.ts` 로 노출»만 요구하면 구현자가 카드와 규칙 사이에서 막힌다.
- 그래서 수용 기준에 쓰기 전에 **서버에서만 부르나, 브라우저 부품에서도 부르나**를 묻고, 경로를 함께 적는다: 서버 → `index.ts` · 브라우저 부품 → 서버 전용 의존이 없는 `lib/` 쪽 경로.
