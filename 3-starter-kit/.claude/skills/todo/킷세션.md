# /todo — 킷 저장소 루트 세션 절차 (SKILL.md 의 절차 대신 이것을 따른다)

> 언제: 킷 저장소(GitHub 리모트, `ai-framework` 루트)에서 켠 세션. 배포처 세션은 SKILL.md 그대로.
> 왜 따로: 킷 원격은 GitHub 이고 카드는 사내 GitLab 의 bnsone·파일럿에만 있어 조회마다 `-R` 로 저장소를 못박아야 한다. SKILL.md 머리의 자동 조회(`scripts/todo-head.sh`)는 이 루트에선 엉뚱한 저장소를 본다 — **머리의 «건너뜀»·빈 결과는 정상이니 무시하고 아래를 Bash 로 한 줄씩 직접 조회한다**(파이프·`;` 없이). 루트 `scripts/todo-head.sh` 는 킷 원본 링크다 — 없으면 머리 명령이 실패해 `/todo` 가 시작부터 죽는다.

## 조회 (한 줄에 하나씩)
- 내 담당 카드 — bnsone: `glab issue list --assignee=@me -P 25 -R gitlab.bns.co.kr/bnsone/bnsone`
- 내 담당 카드 — 파일럿: `glab issue list --assignee=@me -P 15 -R gitlab.bns.co.kr/yskim/ai-framework-pilot`
- 내게 온 To-Do·멘션: `glab todo list -P 40 -R gitlab.bns.co.kr/bnsone/bnsone`
- 킷 저장소 상태: `git status --short --branch`
- `x509: OSStatus -26276` 이면 조회 실패지 «카드 없음»이 아니다 — VPN 탓도 아니다(`rules/gitlab-cli.md`).

## 절차
★★**잘려도 이 둘은 지켜라** ①각 선택지는 «무엇이 달라지나»를 한 줄로 적는다 — 내부 분류명 단독 금지 ②착수 결정은 사용자가 한다 — 네가 골라서 시작하지 마라.

**1. 킷 마찰 확인** — 안 닫힌 줄을 세라: `grep -E '^[0-9]{4}-' 3-starter-kit/docs/friction.md | grep -v '\[닫힘:'`
- 결과가 있으면 「안 닫힌 줄 {N}건 — 가장 오래된 {날짜}」 한 줄과 선택지 하나를 올려라.
- **킷 개선은 카드가 아니다** — friction 한 줄 + 커밋으로 그 자리에서 고친다.
- ⚠️`^2026-` 처럼 연도를 고정하지 마라 — 해가 바뀌면 «0건»이라는 거짓 안심이 된다.

**2. 킷 저장소 동기 확인** — 상태 조회의 `--branch` 줄에 `ahead`·`behind` 가 있으면 그것부터 알려라. 변경 파일이 남아 있으면 «미완 작업»으로 취급하고 무엇인지 먼저 보여라.

**3. 배포처에 «안 간 킷 커밋» 확인** — `bash 3-starter-kit/scripts/check-kit-sync.sh /Users/ysk/orca/projects/bnsone` 한 줄이면 된다(가벼우니 매번).
- 종료 0 = 넘길 것 없음 · 1 = 목록 출력 · **2 = 판정 불능**(«깨끗»이 아니다 — 먼저 `git fetch` 하고 다시).
- ⚠️두 곳의 «글»을 대조하지 마라 — 배포처는 스택 경로·사내 표현이 의도적으로 다르다(2026-09-16 실측: 30개 파일·307줄이 거의 다 그 차이).
- 이 검사기는 글을 안 보고 **마지막으로 넘긴 킷 커밋 이후의 킷 커밋**만 센다. 파일럿은 후순위(오너 결정) — 물을 때만 경로를 바꿔 넣어라.

**4. 담당 구분** — 위 카드 목록 중 **다른 세션(bnsone·파일럿 세션) 몫**이 대부분이다. 킷 세션이 손댈 것은 ⑴킷 저장소 파일 ⑵킷 마찰 ⑶사용자가 명시적으로 시킨 것뿐이다. **남의 카드를 열어 ㉠ 결정거리를 만들지 마라.**

**5. 번호 선택지로 제시** — 3~5개, 각 줄에 «무엇이 달라지나». 마지막 줄은 `▶ 다음: …` 로 사람 몫으로 끝낸다.

**보고 서식**: 3구획(㉠지금 정할 것 ㉡나중에 ㉢알아만 둘 것) — 빈 칸도 "없음". 존댓말. 표·군더더기 금지, 5줄 이내.
- ★★**㉢에는 «내가 못 고치는 것»만 넣어라.** 적기 전에 「이걸 지금 고칠 수 있나?」를 묻고, 고칠 수 있으면 그 자리에서 고쳐라(킷 개선은 friction 한 줄 + 커밋). ㉢을 «나중에 볼 것» 서랍으로 쓰면 아무도 다시 안 본다(오너 지적 2026-09-10).
- ★**0단계 — 설정 어긋남**: `permissions.defaultMode` 가 프로젝트 `.claude/settings.json` 에 박혀 있으면 오너의 전역 설정을 말없이 덮는다. 있으면 그 줄을 지우고 알려라(2026-09-09: 한 세션이 `acceptEdits` 를 박아 오너 `auto` 가 하루 종일 죽어 있었다).
