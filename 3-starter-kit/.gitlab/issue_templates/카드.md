## 수용 기준 (요약)
- [ ] (기준 1) 〔검수확인〕 ← 검수하는 사람이 화면에서 직접 볼 수 있는 것

## 검수 (누가 완료를 확인하나)
- 검수: @누구 (**비우면 카드 담당자(구현자)가 검수**). 검수는 전담자가 없다 — 개발자든 비개발자든 지정된 사람이 배포 화면을 확인하고 카드를 닫는다(화면 기준 — 코드 품질은 CI·AI리뷰·고위험 승인이 본다). **다른 사람 지정은 선택**이다 — 만든 사람 아닌 눈이면 더 좋지만 조건은 아니다. 규칙은 "**화면을 직접 본 사람의 확답 없이는 닫지 않는다**"이지 "다른 사람이어야 한다"가 아니다
- (예외) **화면 없는 카드**(인프라·docs·API 노출)는 검수 생략 — 증거 댓글 + `셀프완료` 표식 후 닫는다(전이표의 셀프완료 경로)

## 위험도
- 아래에 해당하면 **`고위험` 라벨**을 단다(= 경고 레인 — 머지 전 **AI 경고 리뷰 + 증적 3종** 후 본인이 게이트 실행·머지. 동료 승인은 선택): 유형 목록 정본 = 팀 CLAUDE.md '머지 등급' 절(인증·결제성·DB 마이그레이션·shared 승격·핫스팟 등). 해당 없으면 비움. (AI가 `/card`로 만들면 자동 판정)
