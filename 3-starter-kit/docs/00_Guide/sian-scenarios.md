# 시안 허브·채택 — 예상 시나리오와 대응 (자동 로드 X)

> 화면 시안을 **허브에서 보고 → 체크박스로 고르고 → `/ui 시안 채택`으로 확정**하는 흐름에서 자주 나는 상황과, 그때 **AI(개발자 세션)·사람이 각각 무엇을 하는지**. 스킬 문구가 실제 행동으로 이어지는지 점검하는 기준표.

## A. 결정(선택) 관련

| 상황 | 누가·무엇 | 스킬 어디에 |
| --- | --- | --- |
| **체크박스에 2개 이상 체크** (GitLab은 상호배타 X) | AI가 **채택 중단** → "여러 안이 체크됨 = 미결정. 하나만 남겨 달라"고 결정권자에게 **확인 요청**. 임의로 하나 고르지 않음 (`glab issue view`로 `- [x]` 읽음) | `/ui` 갈래 2 · 0단계 |
| **인자 없이 채택을 시도**했는데 체크·구두지시 **둘 다 없음** | AI가 "아직 선택 전"으로 보고 채택 안 함 → 허브 링크와 함께 선택 재안내 | `/ui` 갈래 2 · 0단계 |
| 구두/채팅으로만 "B안" 전달(카드 미체크) | AI는 지시대로 채택하되, **카드에도 체크 반영**(기록 일치) 후 확정 | `/ui` 갈래 2 |
| 채택 뒤 "역시 A안" 번복 | 새 `/ui 시안 채택 {화면} A` 재실행 — 갤러리 배지·notes를 A로 갱신, 이전 결정 줄은 notes에 "변경(날짜·사유)"로 남김(덮어쓰지 말 것). 이미 구현 착수했으면 변경 영향은 `/change` | `/ui` 갈래 2 + CLAUDE.md 변경·삭제 |
| 안을 못 고르겠음(더 필요) | 추가 안 요청 → `/ui 시안 {화면}` 재실행으로 후보 보강(기존 안 유지, 새 안 추가) | `/ui` 갈래 1 |

## B. 허브·인프라 관련

| 상황 | 대응 | 근거 |
| --- | --- | --- |
| 시안 push했는데 허브에 안 보임(≤30초) | 정상 — git-sync 폴링 주기 30초. 그 이상이면 `kubectl logs deploy/sian-mockups -c git-sync`(인증·네트워크 확인) | `sian-hub-setup.md` |
| 브라우저 "주의 요함/인증서 경고" | HTTP 세팅이면 정상(비민감 정적). 운영 전환 시 와일드카드 인증서 적용 | `sian-hub-setup.md` 트러블슈팅 |
| 허브 페이지 자체가 안 뜸 | DNS(A레코드) 또는 파드 상태 확인 `kubectl get pods -l app=sian-mockups` | `sian-hub-setup.md` |
| 허브 랜딩/설정 바꿈 | ConfigMap 갱신 후 **`kubectl rollout restart deploy/sian-mockups`**(nginx 재로드) — 안 하면 옛 설정 유지 | `sian-hub-setup.md` 트러블슈팅 |
| 새 프로젝트 추가 | 배포 토큰 → git-sync 사이드카 1개 + nginx location 1블록 + 랜딩 카드 1개 | `sian-hub-setup.md` §프로젝트 추가 |
| 인스턴스 Pages 정상화됨 | CI `pages` 잡으로 이관, 허브 철거 가능(허브는 어디까지나 아티팩트 버그 우회) | 파일럿 #17 |

## C. 순서·경계 관련

| 상황 | 대응 |
| --- | --- |
| 기획자가 화면 후보를 먼저 보고 싶음(시안 발주) | 카드로 요청(제목 예 `{화면} 시안 요청` — GitLab 가이드 §5-1 0단계) → 개발자 `/ui 시안 {화면}` → 후보 발행 시 요청 카드 닫힘 + **시안 선택 카드**(체크박스)가 결정권자 앞으로. 요청 카드와 선택 카드는 별개(전자=발주, 후자=`/ui`가 발행하는 결정 장치) |
| `/scaffold`(앱 골격) 전에 시안부터 보고 싶음 | 가능 — 허브는 `docs/`만 보므로 앱 코드 없어도 발행됨(과거 "검수 서버 이후" 전제 폐기) |
| 탈락안을 다시 보고 싶음 | `docs/05_UIUX/_drafts/{화면}/`에 보관됨(삭제 안 함) — 갤러리에 `class="dropped"` 흐린 링크로 남김 |
| 시안 채택이 STEP 진행에 반영 안 됨 | `/ui 시안 채택`이 `_STEP_INDEX` STEP5 행을 🔄/링크로 갱신 — 누락 시 수동 확인 |
| "이미지로 보여줘"·"채팅으로 파일 줘" 재요청 | ❌ 기각된 경로 — 허브 링크로 안내(잘림·인터랙션 불가 이유 설명) |
| **"합쳐진 최종 앱"을 보고 싶음** | 시안 허브가 아니라 **검수 서버**(선택안을 `/dev`로 구현 → main 머지 → 자동 배포)에서 본다. 허브는 화면별 **후보**만(연결·데이터 없음). **구현 전이면 아직 없음** — 시안 고르고 `/dev` 시작해야 생김. 시안을 스티칭한 가짜 앱 층은 두지 않음(진짜 앱이 통합 뷰) |

> 이 표의 각 "AI가 …" 항목은 **스킬 문구가 실제 행동을 유도하는지**를 헤드리스(`claude -p`) 행동 시뮬로 확인한다(특히 A의 중복체크). 통과 못 하면 스킬에 **명시 단계**로 승격.
